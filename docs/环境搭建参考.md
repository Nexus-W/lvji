## 二、三个必须先解决的问题

### 1. Flutter 要装在 D 盘，不能装 C 盘

C 盘只剩 19 GB。Flutter 全家桶（SDK + pub 缓存 + Gradle 缓存 + 构建产物）大概要 **15～20 GB**，装 C 盘会直接把系统盘吃干净。

安装位置统一放 D 盘：

```
<Flutter SDK>          ← Flutter SDK
<Pub 缓存>        ← Dart 包缓存
<Gradle 缓存>      ← Gradle 缓存（默认在 <用户目录>\.gradle，必须迁走）
```

### 2. cmdline-tools 缺失，必须补上

Flutter 依赖它来管理 SDK 组件和接受许可。补法有两条，**推荐第一条**：

**方式 A（最省事）**：打开 Android Studio → Settings → Languages & Frameworks → Android SDK → SDK Tools 标签 → 勾选 **Android SDK Command-line Tools (latest)** → Apply，它会自己装到 `<Android SDK>\cmdline-tools\latest`。

**方式 B（手动）**：下载 `commandlinetools-win-*.zip`，解压后确保目录结构是：

```
<Android SDK>\cmdline-tools\latest\bin\sdkmanager.bat
```

注意必须是 `cmdline-tools\latest\bin` 这一层，多套一层或少套一层 Flutter 都认不出来，这是最常见的踩坑点。

### 3. JDK 25 可能过高

Android Studio 自带的是 OpenJDK **25**。Flutter 的 Android 构建链（Gradle + AGP）通常对 JDK 17～21 支持最稳，JDK 25 有概率报：

```
Unsupported class file major version 69
```

**先不用管**，等真报错了再处理。处理方式：装一个 JDK 21（Temurin 或 MS OpenJDK），然后

```
flutter config --jdk-dir "<JDK 21>"
```

## 三、搭建步骤

### 第 1 步：下载 Flutter SDK

用 Git 直接克隆（你已经有 Git 2.55）：

```bash
mkdir -p /d/dev
cd /d/dev
git clone --depth 1 -b stable https://github.com/flutter/flutter.git flutter
```

> 国内网络慢的话，先把镜像配上再执行：
> ```bash
> set PUB_HOSTED_URL=https://pub.flutter-io.cn
> set FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
> ```

### 第 2 步：配环境变量

在「系统属性 → 环境变量 → 用户变量」里新增：

| 变量名 | 值 |
|---|---|
| `Path`（追加） | `<Flutter SDK>\bin` |
| `ANDROID_HOME` | `<Android SDK>` |
| `ANDROID_SDK_ROOT` | `<Android SDK>` |
| `JAVA_HOME` | `<Android Studio>\jbr` |
| `PUB_CACHE` | `<Pub 缓存>` |
| `GRADLE_USER_HOME` | `<Gradle 缓存>` |

**改完必须重开一个终端窗口**，否则读不到新变量。

### 第 3 步：验证

```bash
flutter --version
flutter doctor -v
```

`flutter doctor` 里 Android 那一段如果显示 ✅，就说明环境通了。

### 第 4 步：接一台真机

**这一步别省。** 你这个 App 的核心是读手机相册，模拟器里没有你真实的几千张照片，跑起来看不出版面效果。

- 手机开「开发者选项 → USB 调试」，插线，手机上点「允许」
- 验证：`adb devices` 能看到设备号

（建模拟器也行，但只适合看界面骨架，不适合验证真实素材。）

## 四、预期会踩的坑

| 报错 | 原因 | 对策 |
|---|---|---|
| `cmdline-tools component is missing` | 第二步没做 | 补 cmdline-tools，注意目录层级 |
| `Android license status unknown` | 许可没接受 | `flutter doctor --android-licenses` 一路 y |
| `Unsupported class file major version 69` | JDK 25 太高 | 装 JDK 21，`flutter config --jdk-dir` 指过去 |
| `Could not resolve all files for configuration` | Gradle 下载被墙 | 在 `build.gradle` 加阿里云 maven 镜像 |
| `Waiting for another flutter command to release the startup lock` | 上次异常退出 | 删 `<Flutter SDK>\bin\cache\lockfile` |
| C 盘突然少十几 G | Gradle 缓存默认在 C 盘 | 确认 `GRADLE_USER_HOME` 已指向 D 盘 |

## 五、给你的一句话建议

环境这件事，**先做第 1、2、3 步就够**（大概 30 分钟）。真机和 cmdline-tools 可以等代码写出来、要跑的那一刻再处理。
