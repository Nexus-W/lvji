# 页面规格 · 行程地图页

> 对象：`/trip/:id/map`（原型 `c1-prototype.html`）
> 本文档描述**唯一正确的形态**。执行者按本文实现，不要沿用当前正式版的实现。
> 文中所有尺寸单位为 **dp（逻辑像素）**，基于 390×844 基准屏（iPhone 14 / 主流安卓）。其它屏宽按 §1.3 规则换算。

---

## 0. 这一页是干什么的

用户打开行程，想回答两个问题：

1. **这趟行程，照片都拍在哪儿？** → 地图上的点位
2. **某一天拍了什么？** → 底部按天分组的网格

两者的关系是**联动**：滚网格 → 地图跟着高亮；点地图 → 网格滚到那天。

这一页是「看」的页面，不是「编辑」的页面。唯一的写操作是**长按进入选片模式**批量加精选 / 删除。

## 1. 页面结构

### 1.1 五个垂直区域（固定顺序，不可调换）

```
┌─────────────────────────────┐
│ ① 状态栏（系统）              │  ← 不绘制，但要避让
├─────────────────────────────┤
│ ② 地图区（46% 高度）          │
│    · 底图                    │
│    · 点位与标签（markers）     │
│    · 顶部控件（行程名/复位）    │
│    · 右侧控件（+/−/›）        │
│    · 提示条（toast）          │
│    · 底图说明（maptag）       │
├─────────────────────────────┤
│ ③ 拖拽条（24）               │
├─────────────────────────────┤
│ ④ 抽屉（剩余高度，可拖拽）     │
│    · 按天分组的照片网格        │
├─────────────────────────────┤
│ ⑤ 底部导航（56 + 安全区）      │
└─────────────────────────────┘
```

### 1.2 尺寸表

| 区域 | 高度 | 说明 |
|---|---|---|
| ② 地图区 | `H × 46%` | H = 屏幕高 − 状态栏 − 底部导航 |
| ③ 拖拽条 | 24 | 不可省略，是抽屉的手势入口 |
| ④ 抽屉 | `H × 54% − 24` | 最小 180，最大 `H − 200` |
| ⑤ 底部导航 | 56 + 安全区 | 见 §8 |

> 地图区与抽屉高度之和恒等于 H。拖动拖拽条时两者此消彼长，**不出现空白也不溢出**。

### 1.3 安全区

- 顶部：`MediaQuery.padding.top`，所有覆盖在地图上的控件**必须**从 `padding.top + 8` 开始。
- 底部：`MediaQuery.padding.bottom`，底部导航高度 = `56 + padding.bottom`。
- 左右：`8`。

> **当前实现的错误**：顶部胶囊压在状态栏下面，"复位"被时间遮住。原因是没有为 `padding.top` 留位。

## 3. 地图层

### 3.1 底图（自绘，不接第三方 SDK）

底图必须是**矢量绘制**，包含三类元素：

| 元素 | 画法 | 透明度 |
|---|---|---|
| 等高线 | 6–10 条闭合样条，线宽 1 | 0.10 |
| 水系 | 2–3 条河流曲线 + 1 个湖泊轮廓 | 0.12 |
| 地名 | 6–10 个静态文本（苍山、双廊、沙溪、凤仪…） | 0.55 |

**要求**：

- 底图随地图一起平移缩放（`transform: translate + scale`），不是固定背景。
- 地名文字**不随缩放改变字号**（始终 11sp），只改位置。否则放大后地名字会糊。
- 底图内容与实际地理**不需要精确对应**，但必须"看起来像地形图"：有起伏、有水、有地名。

### 3.2 投影与视口

```
用户坐标系：0..1000 的方形（与原型一致）
屏幕坐标 = (user - center) * scale + viewportCenter

渲染：整张底图放在一个 1000×1000 的层里，
      通过 transform: translate(tx,ty) scale(s) 变换
```

- 初始 `scale`：让所有照片点的包围盒 + 20% 边距刚好填满地图区。若只有一个点或没有点，用 `scale = 1.6` 居中。
- `scale` 范围：`[0.5, 4.0]`。
- 初始中心：所有点的几何中心。

### 3.3 聚合（cluster）

照片点多时不能一个个画，必须先聚合：

```
1. 把所有照片点投影到屏幕坐标
2. 用网格聚类（cell = 48dp）：
   key = (floor(x/48), floor(y/48))
   同一 cell 内的点合并为一个 cluster
3. 每个 cluster 计算：
   - 中心点 = 成员的平均坐标
   - count = 成员数
   - 主地点名 = 成员中出现次数最多的 place
   - 缩略图 = 成员中 is_cover 优先，其次 is_featured，再次最新
   - 标记 = 成员中所有 gold/green/violet 的去重集合
4. **同一 place 只允许存在一个 cluster**：
   若两个 cluster 的 place 相同，合并到 count 多的那个
```

> **当前实现的错误**：截图里「洱海东岸」出现两次（28 张、88 张），「大理古城」出现两次（9 张、9 张）。
> ——聚类后没有按 place 去重。**必须做第 4 步。**

### 3.4 标签布局（这一页最关键的算法）

标签不能直接摆在点位正上方，否则必然重叠。**必须做碰撞检测 + 多候选布局。**

#### 元素尺寸

| 元素 | 尺寸 |
|---|---|
| 气泡（缩略图 + 标题 + 张数） | 宽随内容 96–140，高 44 |
| 单独圆点（无标签时） | 直径 20，内含数字 |
| 点位锚点 | 视觉中心 = 气泡的**左中**或**右中**对齐点位 |

#### 候选位置（按优先级）

```
设点位 P(x,y)，气泡宽 W、高 H，间隙 g = 8

候选 1：右侧居中     (x + 10,        y - H/2)
候选 2：右侧偏上     (x + 10,        y - H - 2)
候选 3：右侧偏下     (x + 10,        y + 2)
候选 4：左侧居中     (x - W - 10,    y - H/2)
候选 5：左侧偏上     (x - W - 10,    y - H - 2)
候选 6：上方居中     (x - W/2,       y - H - 12)
候选 7：下方居中     (x - W/2,       y + 14)
```

#### 放置流程

```
输入：clusters 按 count 降序排序
已放置列表 placed = []

for c in clusters:
    for pos in 候选位置(c):
        矩形 r = (pos, pos + (W,H))
        if 超出可视区（含 8dp 内缩）: continue
        if r 与 placed 中任一矩形相交（间距 < 4dp）: continue
        采用 pos，placed.push(r)，break

    if 没有任何候选可用:
        降级为"只画圆点"（直径 20，内含 count）
        —— 不要强行画标签
```

#### 硬性规则

1. **每次重绘必须全量清空 markers 容器再重建**，不做增量更新。
   > **当前实现的错误**：标签有重影（能看到半透明的旧标签叠在新标签上），说明重绘时旧节点没有移除，或者做了透明度过渡但没清理。
2. **缩放/拖动时不重排标签**（否则会跳动），**松手后重排一次**。
3. 标签的 `zIndex` = `1000 - count`，张数多的在上面。
4. 被选中那天的 cluster 加亮：边框透明度 0.5→1.0，背景 0.86→0.94。

#### 视觉结构（气泡内部）

```
┌────────────────────────────┐
│ ┌────┐  洱海东岸           │
│ │ 图 │  88 张  ● ● ●       │
│ └────┘                     │
└────────────────────────────┘
   ↑36×36      ↑11sp   ↑9sp
   圆角6        主文     三色点
```

- 缩略图 36×36，圆角 6，左边距 4，垂直居中。
- 标题 11sp w500 #E9EEF6，单行省略。
- 副行 9sp #9AA6B6：`{count} 张` + 三色圆点（每个 6dp，间距 3）。
- 内边距：左右 10/12，上下 4。

### 3.5 手势

| 手势 | 行为 | 约束 |
|---|---|---|
| 单指拖动 | 平移地图 | 松手后重排标签 |
| 双指捏合 | 缩放 | 以两指中点为锚点 |
| 单击气泡 | 选中该 cluster：抽屉滚到对应天并高亮该天 | — |
| 单击空白 | 取消选中 | — |
| 双击 | 放大一级（×1.5） | — |
| 长按气泡 | 无（长按留给抽屉网格） | — |

**边界**：地图不能被拖出可视区（`tx/ty` 做 clamp），至少保留 100dp 的底图在视口内。

### 3.6 与抽屉的联动

| 触发 | 行为 |
|---|---|
| 抽屉滚动，某天的标题进入抽屉顶部 1/3 | 地图把该天的 cluster 高亮，并在顶部显示「10月2日 · 地图已跟随」1.5 秒后淡出 |
| 点 cluster | 抽屉 `scrollTo` 到该天标题，滚动时长 300ms，缓动 easeOut |
| 手动拖动地图 | 取消"跟随"状态，直到下一次滚动抽屉 |

> 联动必须是**单向触发 + 防抖**（滚动停止 120ms 后才算"进入某天"），否则快速滑动时地图会疯狂闪。

## 5. 右侧控件（缩放 + 跳转）

```
                    ┌────┐
                    │ +  │  ← 36×36
                    ├────┤
                    │ −  │  ← 36×36
                    ├────┤
                    │ ›  │  ← 36×36，进入精选展板
                    └────┘
```

| 项 | 值 |
|---|---|
| 位置 | 右边 12，底部距抽屉顶 12 |
| 尺寸 | 36×36，圆角 10，间距 10（组内），整组垂直排列 |
| 背景 | `rgba(8,14,18,.86)`，边框 `rgba(255,255,255,.08)` |
| 字号 | + / − 用 16sp 符号，› 用 14sp |

行为：

- `+`：`scale × 1.4`，上限 4.0，以地图中心为锚点。
- `−`：`scale ÷ 1.4`，下限 0.5。
- `›`：跳转 `timeline-page`（精选展板）。

> **当前实现的错误**：三个按钮浮在地图中间偏右，且没有对齐成组——定位基准错了（用了固定 top，没跟随抽屉高度）。

## 6. 提示条

两种，**同一时刻只显示一个**，层级在地图之上、markers 之下（`zIndex: 3`，markers 为 4）。

| 提示 | 触发 | 内容 | 时长 |
|---|---|---|---|
| 首次提示 | 首次进入本页 | 「滚动下方时间轴，地图会跟着走」 | 4 秒后自动消失，或用户首次滚动抽屉时立刻消失 |
| 跟随提示 | 抽屉滚到某天 | 「10月2日 · 地图已跟随」 | 1.5 秒 |

样式：居中，距地图顶 56（即控件下方），高 30，圆角 15，
背景 `rgba(8,14,18,.9)`，文字 11sp #9AA6B6，左右内边距 14。

> **当前实现的错误**：首次提示压在 cluster 标签上（截图里"滚动下方时间轴…"盖住了"双廊"）。
> 原因是提示条的 zIndex 高于 markers，且没有避让。

## 7. 底部抽屉

### 7.1 拖拽条

- 尺寸：整行高 24，中间一根 40×4 圆角 2 的横条，颜色 #2A3441。
- 手势：按住上下拖动改地图/抽屉比例；松手吸附到最近的 30% / 46% / 62%（三个档位），动画 200ms。
- 拖动时**不重排标签**，松手后重排。

### 7.2 按天分组

每天一个区块：

```
┌──────────────────────────────────────┐
│ 10月2日 · 大理古城              168 张 │  ← 标题行，高 36
├──────────────────────────────────────┤
│  ┌────┬────┬────┬────┐               │
│  │    │    │    │    │               │  ← 4 列网格，间隙 2
│  ├────┼────┼────┼────┤               │
│  │    │    │    │    │               │
└──────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 标题行 | 左：`{日期} · {地点}` 12sp w600 #E9EEF6；右：`{n} 张` 10sp #65707F |
| 标题行高度 | 36，左内边距 14，右内边距 14 |
| 网格 | 4 列，间隙 2，左右不留边距（贴边） |
| 缩略图 | 正方形（1:1），无圆角 |
| 保护区 | 抽屉底部留 8dp + 安全区，避免最后一个网格被底部导航裁切 |

> **当前实现的错误**：截图底部有一排被裁掉一半的照片，说明网格容器没有为底部导航预留高度。

### 7.3 缩略图角标

每张缩略图**左上角**可有一个 8dp 圆点：

| 颜色 | 含义 | 位置 |
|---|---|---|
| 金 #D9C48A | 封面 | 左上 6,6 |
| 绿 #3DDC97 | 精选 | 左上 6,6（有金时移到 18,6） |
| 紫 #9B8AE6 | 有备注 | 同上依次右移 |

> 三色可同时存在，最多显示 3 个点。同一时间轴、地图、大图三处的含义必须一致。

### 7.4 选中模式（长按进入）

- 长按任意缩略图 500ms → 进入选中模式，该图被选中。
- 进入后：
  - 抽屉顶部出现工具条（替代标题行）：`已选 N 张` + 右侧三个按钮 `加入精选` / `删除` / `取消`。
  - 地图区压缩到 30%（动画 200ms），给网格更多空间。
  - 点击缩略图切换选中（选中显示 2dp 绿边 + 右下角勾）。
  - 底部导航隐藏。
- 退出：点 `取消`，或选中数为 0 时自动退出。

工具条规格：高 44，背景 #151E27，底部 1px 分割线；按钮 12sp，`删除` 用 #FF7A8A。

### 7.5 状态

| 状态 | 表现 |
|---|---|
| 无照片 | 网格区显示：「这天还没有照片」+ 一行灰字「去导入素材」 |
| 整行程无照片 | 抽屉只显示一个居中的「还没有照片，先导入一些」+ 一个「去导入」按钮 |
| 加载中 | 骨架屏：4 列 × 3 行灰块，不带闪烁动画 |

## 8. 底部导航

- 高度 56 + 安全区，背景 #0F141B，顶部 1px #232C39。
- 两个 tab：**行程**（`trips`）/ **地图**（当前，高亮）。
- 每个 tab：图标 20×20 + 文字 10sp，垂直排列，间距 2。
- 当前 tab：图标与文字为 #3DDC97；非当前 #65707F。
- 点击切换，保留各自页面的滚动位置。

> 只有两个 tab。设置不在这里（在行程列表的「＋」菜单里）。

## 12. 性能与边界

- 点位超过 300 个：只渲染聚合后的 cluster（通常 5–20 个），**不要渲染原始点**。
- 标签重排：`O(n²)`（n = cluster 数），n ≤ 30 时可忽略；超过 30 时只对前 20 个画标签，其余降级为圆点。
- 缩略图：必须用 `cacheWidth` 解码（宽度 = 屏宽/4 × 设备像素比），否则大图会 OOM。
- 拖动地图时：禁止触发抽屉滚动监听（避免联动抖动）。

## 14. 实施建议

**不要在当前实现上打补丁。** 现有版本的问题不是"某几处没调好"，而是缺少三个基础机制：

1. 聚类去重（§3.3）
2. 标签碰撞布局（§3.4）
3. markers 全量重建（§3.4 硬性规则 1）

补丁式修改会不断冒出新的重叠组合。建议**整页重写** `MapPage`，按本文的五个区域自上而下搭，先跑通"静态渲染 + 无重叠"，再加手势与联动。

**重写顺序**（每步可独立验证）：

```
① 五区域骨架 + 尺寸（无数据，先看布局对不对）
② 底图绘制（等高线/水系/地名三层）
③ 照片点 → 聚类 → 去重（打印 cluster 数，确认没有同 place）
④ 标签碰撞布局（构造 30 个假点，看是否零重叠）
⑤ 手势（拖动/缩放/clamp）
⑥ 抽屉分组网格 + 三色角标
⑦ 联动（滚动↔高亮、点击↔滚动）
⑧ 拖拽条与三档吸附
⑨ 选中模式
```

第 ④ 步是分水岭：**如果 30 个假点还能重叠，后面全白做。**
